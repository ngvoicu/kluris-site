02  ·  Beat 1 · Set up

Install kluris. Create a brain.

A brain is a git repo of curated markdown that every AI agent on your team reads as a subject matter expert. One command to install. One wizard to create your first one.

macOS · zsh/bash Terminal 
$ brew install pipx
$ pipx ensurepath
$ pipx install kluris
Linux · bash Terminal 
$ python3 -m pip install --user pipx
$ pipx ensurepath
$ pipx install kluris
Windows · PowerShell Terminal 
> pip install pipx
> pipx ensurepath
> pipx install kluris
kluris create — interactive wizard Terminal

03  ·  Beat 2 · Teach

Teach the brain what your team knows.

Open your AI agent in a project — a repo, a service, a codebase — and one slash command, /kluris, turns the conversation into knowledge. Say learn, remember, or anything in between; the agent picks the right behavior. Lobes are folders you create to group related ideas — one per concern, as many as you need. Neurons are the markdown files inside them. You approve every neuron before it lands.

/kluris learn · analyze code, propose neurons In your AI agent · in a project

04  ·  Beat 3 · See

See the whole brain at a glance.

One command renders every neuron as a node and every synapse — a frontmatter link between neurons — as a dashed line. Share it, explore it, find the orphans.

kluris mri — one interactive HTML file Terminal 
$ kluris mri

MRI complete — brain-mri.html
  23 nodes, 31 edges
  → file:///.../brain-mri.html

Interactive features:
  · search any neuron
  · hover to see connections
  · click to inspect content
  · pan and zoom the graph
  · filter by lobe

Share the HTML — it runs anywhere.

A brain replaces a wide file crawl with a targeted lookup — agents burn fewer tokens orienting and more tokens doing real work.

Real output · ngvoicu-sme brain

Colors are lobes · lines are synapses · every dot is a real neuron.

05  ·  Beat 4 · Use

Ask the brain. Get grounded answers.

Every agent on your team can search and query across the brain. The agent shows you exactly which neurons it read — no hallucinations, no vibe.

/kluris search · semantic + keyword lookup In your AI agent · in a project 
> /kluris search auth flow

Found 3 neurons:
  projects/btb-core/auth-flow.md       ★★★
  knowledge/jwt-rotation.md            ★★
  infrastructure/keycloak-setup.md     ★

Run `/kluris open auth-flow.md` to read one.
/kluris what do we know · natural language Q&A In your AI agent · in a project 
> /kluris what do we know about Docker?

Reading:
  infrastructure/docker-builds.md
  infrastructure/environments.md

Search

Context sharing

Onboarding, pairing, code review — every teammate who clones the brain sees the same answer tomorrow.

06  ·  Beat 5 · Grow

Grow it with your team.

Your scaffolded lobes are a starting point, not a cage — add a new one any time a new concern shows up. Ship neurons through git like any other code. Run kluris dream now and then to tidy up maps and synapses.

Add a new lobe Terminal 
$ kluris lobe compliance
✓ Created acme-brain/compliance/

$ kluris lobe gdpr --parent compliance
✓ Created acme-brain/compliance/gdpr/

Ask the agent to seed neurons into the new lobe
whenever a new concern shows up — SOC2, pricing,
migrations, anything.
Share via git Terminal 
$ kluris branch add-auth-decision
✓ Switched to add-auth-decision

(approve neurons in your agent)

$ kluris push
✓ 3 commits · pushed to origin

$ kluris pull
✓ 2 new neurons pulled

Teammates see your neurons on next wake-up.
Housekeeping — run now and then Terminal 
$ kluris dream

acme-brain health report:
  Maps regenerated: 4   OK synapses
  6 automatic fixes applied
  3 dates refreshed from git
  2 reverse links added

Brain is healthy.

Running more than one brain? Each installs as its own /kluris-<name> skill — kluris list to see all, kluris clone to pick one up from git.
